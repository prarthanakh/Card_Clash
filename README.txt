Card Clash 

Compile from this folder:
  Windows:  dir /s /b src\*.java > files.txt   then   javac -d out @files.txt
Packages (all under com.cardclash):
  exception  3 custom exceptions
  model      cards, players, deck, hand, data records
  logic      Game, Strategy classes, interfaces, enums
  database   SQLite classes (NOT needed for the console evaluation)
  ConsoleMain.java  entry point for the text-only version
